# Saha mobile app (Expo)

```bash
cp .env.example .env
npm install
npx expo start
```

On a physical device, set `EXPO_PUBLIC_API_URL` to your computer's LAN IP (not `127.0.0.1`). Android emulator: `http://10.0.2.2:8000`.

See [`../../docs/eas.md`](../../docs/eas.md) for EAS builds and [`../../docs/app-store.md`](../../docs/app-store.md) for App Store submission.
