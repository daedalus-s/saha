# Saha

Saha is a mobile app that finds Hindu slokas and mantras on the web, lists the versions it finds (grouped by script), transliterates them into another Indic script, generates an English meaning, and exports the result as a PDF.

The repo is a monorepo:

| Path | What it is |
| --- | --- |
| [`apps/mobile`](apps/mobile) | Expo (React Native) app — iOS first, Android kept buildable |
| [`services/api`](services/api) | FastAPI backend for search, extraction, transliteration, and translation |
| [`docs`](docs) | Privacy policy, terms, architecture, App Store and deploy runbooks |

The app never holds LLM or search API keys. It talks only to the Python backend.

## Features (v1)

- Search by sloka / mantra name
- Web search with per-script query expansion (Telugu, Tamil, Sanskrit, …)
- Page fetch + LLM verse extraction, with a heuristic fallback
- Script detection and near-duplicate collapsing
- Transliteration: Devanagari, Tamil, Telugu, Kannada, Malayalam, Gujarati, Bengali, IAST, ITRANS
- AI-generated English meaning (labelled as such — not copied from source sites)
- PDF export of original + transliteration + meaning
- Local saved items and recent searches (no accounts)

## Quick start

### Backend

```bash
cd services/api
cp .env.example .env
# edit .env — at minimum set APP_KEY
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # macOS / Linux
pip install -e ".[dev]"
uvicorn app.main:app --reload --port 8000
```

`GET http://localhost:8000/health` should return `{"status":"ok"}`.

Without search/LLM keys the API still boots. Search/extract/translate return clear errors or use the heuristic extractor when `LLM_MODEL=none`.

### Mobile

```bash
cd apps/mobile
npm install
npx expo start
```

Point `EXPO_PUBLIC_API_URL` at the backend (see [`apps/mobile/.env.example`](apps/mobile/.env.example)). For a physical device, use your LAN IP, not `localhost`.

## Environment

See [`services/api/.env.example`](services/api/.env.example). Search uses Brave or Google Programmable Search. Translation/extraction uses LiteLLM (`LLM_MODEL`, plus the matching provider key).

## Legal

Sloka text is treated as public-domain scripture and is shown with source attribution. Site-specific translations and commentary are **not** copied. Meanings are generated by us and labelled “AI-generated meaning; verify with a scholar.”

Privacy policy and terms are in [`docs/privacy.md`](docs/privacy.md) and [`docs/terms.md`](docs/terms.md), and are also served by the API at `/privacy` and `/terms` once hosted.
